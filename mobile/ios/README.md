# iOS project

Platform target is confirmed Android + iOS (docs/architecture.md §6).

This directory is a placeholder. The actual Xcode project (`Runner.xcodeproj`, `Podfile`, etc.) must be
generated by running:

```
flutter create --platforms=ios .
```

from within `mobile/` on a macOS machine with Xcode installed — this cannot be done in the current Linux
dev sandbox (Flutter's iOS tooling requires Xcode/CocoaPods, which only run on macOS).
